# 自测清单

按阶段勾选。前 6 组是**每次发版前必跑**，后 4 组是异常场景。
建议直接在打包产物上跑（双击 `dist\MiaoQiWheel\MiaoQiWheel.exe`），而非源码模式。

---

## 1. 启动与常驻（M0）

- [ ] 双击 exe，3 秒内**托盘出现图标**（可能需要点开托盘折叠区）
- [ ] 气泡提示显示当前触发键（默认「长按 Tab」）
- [ ] 再次双击 exe → **自动退出**，不出现第二个托盘图标（单实例互斥量生效）
- [ ] 任务管理器中内存占用 **< 80 MB**（目标 45~60 MB）
- [ ] 空闲 10 分钟 CPU 占用接近 0

## 2. 呼出与选择（M2）

- [ ] 长按 Tab ≈0.2 秒 → 轮盘在鼠标位置弹出
- [ ] 移动鼠标 → 扇区高亮跟随，**不卡顿**
- [ ] 松开 Tab → 执行选中项（默认第一项是锁屏，**先换成记事本再测**，免得反复锁屏）
- [ ] 短按 Tab → 正常跳格，**不呼出轮盘**
- [ ] 停在盘面正中松开 / 按 Esc → **不执行任何动作**
- [ ] `Alt+Tab` **仍能切换窗口**（钩子放行）
- [ ] 呼出期间正在输入的应用**不丢焦点**（光标不跳走）

## 3. 动作与预设（M3）

- [ ] 打开记事本 / Edge / 资源管理器：各试一次
- [ ] 网址类：能唤起默认浏览器
- [ ] 快捷键类：截图（`Win+Shift+S`）可用
- [ ] 预设「设置音量 35%」→ 系统音量真的变了
- [ ] 预设「切换深色模式」→ 系统主题切换
- [ ] 预设「复制文本」→ 粘贴出来内容正确（含空格与引号）
- [ ] 预设「关机（延迟 30 秒）」→ 建议改成 `shutdown /a` 场景或直接观察倒计时提示
- [ ] 执行失败时有**托盘错误提示**，程序不崩溃

## 4. 设置窗口（M4）

- [ ] 托盘右键 → 打开设置；四页（通用/轮盘选项/帮助/关于）都能打开
- [ ] **改触发键**（如换成 CapsLock）→ 立即生效，**无需重启**
- [ ] 改轮盘大小滑块 → 下次呼出尺寸随之变化
- [ ] 关掉「动画」「毛玻璃」→ 呼出更轻快，无报错
- [ ] 选项页：新增一项、删除一项、上下移、**拖拽排序**
- [ ] 从资源管理器**拖入一个 exe** → 自动加项且带上真实图标
- [ ] 选一个预设（如关机）并改延迟 → 命令框内容同步更新
- [ ] 图标选择器搜索 "lock" → 能搜到并更换图标
- [ ] 开机自启：打开开关 → 任务管理器 → 启动 中看到「MiaoQiWheel」；注销重登录能自启
- [ ] 恢复默认设置 → 六个默认项回来，**选项页同步刷新**
- [ ] 关闭设置窗口 → 程序**不退出**（仍在托盘）

## 5. 视觉与多屏（M5）

- [ ] 毛玻璃能看到背后桌面纹理（不是纯灰）
- [ ] 阴影与高光自然，边缘无黑边、无锯齿
- [ ] 入场 130ms 淡入不拖沓；关掉动画后是瞬时出现
- [ ] 125% / 150% 缩放屏：轮盘大小与位置正确，不模糊
- [ ] 多屏：在**副屏**呼出，盘面完整落在屏内
- [ ] 靠屏幕边缘呼出：盘面被夹取回屏内，不越界

## 6. 稳定性

- [ ] 连续呼出/取消 20 次无异常
- [ ] 呼出后不松开直接锁屏再解锁 → 轮盘不卡死
- [ ] 修改设置 20 次后 `settings.json` 内容正确、无损坏
- [ ] 托盘右键 → 退出 → 进程**完全退出**（任务管理器无残留）

## 7. 异常场景

- [ ] 拔掉外接屏 / 改变缩放后呼出 → 不崩溃、位置正确
- [ ] 以管理员权限运行某程序（如任务管理器）后仍呼出 → 记录是否失效（已知限制：UIPI）
- [ ] 设置里把主键设为已占用的键（如 Ctrl+C）→ 提示或降级，不卡死
- [ ] 断电式杀进程后重启 → 配置文件仍可读取（原子写入）

## 8. 便携性

- [ ] 把 `dist\MiaoQiWheel` 整个目录拷到 U 盘另一台机器 → 能直接运行
- [ ] 只拷贝 exe → **预期失败**（缺依赖），用于验证"必须整目录分发"的说明是否到位

## 9. 打包产物检查（M6）

- [ ] `dist\MiaoQiWheel\MiaoQiWheel.exe` 存在且图标正确
- [ ] 目录内有 `_internal\`，且 `qtawesome\fonts\*.ttf` 存在（否则图标全变空心圆）
- [ ] 右键 exe → 属性 → 详细信息 → 版本号与关于页一致
- [ ] `MiaoQiWheel-vX.Y.Z-portable.zip` 可正常解压，内含 `使用说明.txt`

## 10. 已知限制（不必修，但要知道）

- 以管理员权限运行的程序可能截获低级钩子 → 轮盘呼不出（UIPI 限制）
- 部分全屏独占游戏内可能无效
- 关机/重启预设依赖 `shutdown.exe`，被组策略禁用时无效
- 朗读文本依赖系统语音（SAPI），中文语音包缺失则为英文发音
